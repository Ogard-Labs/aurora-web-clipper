# Sign-in provider logos

Provider-published artwork, byte-identical to `apps/web/src/assets/auth/` in
Ogard-Labs/auroradocs, which records where each file was downloaded. Don't
redraw, recolour or optimize them. Google forbids a monochrome G on sign-in
buttons, and Google and Microsoft stay in their standard colours. Apple and
GitHub have approved black and white treatments, so those follow the theme.
